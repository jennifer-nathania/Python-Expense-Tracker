# Python-Expense-Tracker-2025
A Python-based expense tracker with categorized income/expense management, balance tracking, recursive category search, and file-based data storage.

# ✨ Features
- Add income and expense records
- View all financial records and current balance
- Delete records by ID
- Search records by category and subcategory
- Hierarchical category system
- Recursive category validation and searching
- Automatic data saving/loading using text files
- Exception handling for invalid inputs and corrupted files
